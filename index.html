Version History & Release Ledger

Beta 0.17.0

Administrative audit log and complete architectural release history.

  • Beta 0.17.0 Latest

    Streamlined Navigation Header: Removed the redundant "+ Add Shows" header button to declutter top-level navigation, standardizing title discovery and library additions through the dedicated "Explore Streaming Services" and "Smart Recommendations" dashboards.

  • Beta 0.16.0

    Hardened Session Lockout & Master Password Enforcement: Resolved admin authorization persistence across account logouts by strictly clearing session privileges upon logout, settings closure, and view navigation. Sealed administrative settings by requiring the established master password for all protected access and added mandatory current-password verification before any password update.

  • Beta 0.15.0

    Header Version Button & Administrative Password Protection: Relocated version indicator to the header alongside tv.seelye.info in matched typography and size. Converted version indicator into an interactive trigger that unlocks the comprehensive release history rendered 100% inline in accordance with zero-modal architecture. Safeguarded both Settings and Version History with master admin password protection, Web Crypto SHA-256 one-way hashing, cloud sync via system_settings, and 5-attempt rate-limited brute-force lockout safeguards.

  • Beta 0.14.0

    Browser Tab App Icon & Brand Identity: Added custom browser tab favicons tailored to the app's dark neon aesthetic. Includes an ultra-crisp vector SVG favicon (favicon.svg) featuring a glowing electric-cyan widescreen TV monitor with centered play beacon on obsidian slate, complemented by high-res PNG and Apple Touch icons (apple-touch-icon.png) and standard ICO fallback for Chrome, Edge, Firefox, and Safari tabs.

  • Beta 0.13.0

    Strict Category & Tone Recommendation Boundaries: Comprehensive taxonomy overhaul classifying every catalog and TMDB title into distinct primary categories (lighthearted comedy, prestige drama, dark supernatural mystery, mind-bending sci-fi, gritty crime, action-thriller) and explicit tones (lighthearted, wholesome, dark, gritty, tense, serious, satirical). Strict mood isolation eliminates overlap, ensuring dark gothic mysteries like Wednesday, caustic satires like The Bear, and intense thrillers like Squid Game are never cross-recommended in lighthearted comedy queues or confused with pure prestige dramas.

  • Beta 0.12.0

    30-Second Entertainment Taste Quiz: Added a fast, interactive 4-question taste quiz rendered 100% inline in Smart Recommendations. Calibrates the recommendation queue in under 30 seconds across mood/vibe, story world, narrative pacing, and streaming service affinities with instant ranking boosts, custom rationale badges, and one-click retake/reset controls.

  • Beta 0.11.0

    IMDb Show Details Pop-up Modal: Decoupled show addition from card clicking so shows are only added via the explicit "+ Add to Library" button. Clicking any show's picture opens a dedicated IMDb pop-up modal over the screen with full plot synopses, cast, seasons, ratings, direct IMDb link, and an interactive "x" close button.

  • Beta 0.10.0

    Apple TV+ Streaming Option: Integrated Apple TV+ across the application including personal library provider filters, explore streaming services discovery with acclaimed hits (Ted Lasso, Severance, Silo, Slow Horses, and more), taste profile analysis, and TMDB addition.

  • Beta 0.9.0

    Architecture & Smart Recommendations Overhaul: Separated personal My Library from Explore Streaming Services into dedicated inline views with real-time counters and status filters. Added multi-vector intelligent recommendation engine analyzing watch history, thumbs-up ratings, and genre profiles with contextual rationale badges.

  • Beta 0.8.0

    Streaming Service Discovery: Clicking any streaming service (Netflix, Disney+, Peacock, Hulu, Prime Video, YouTube TV) instantly displays currently popular and classic shows for that service with one-click library addition.

  • Beta 0.7.0

    Fixed TMDB search cut-off posters: Eliminated inner scroll-traps and expanded result card grid (min 185px). Made entire show card clickable for instant library addition with responsive visual feedback, resolved Supabase UUID formatting and guest mode storage persistence, and enabled Enter key search with catalog-to-TMDB fallback.

  • Beta 0.6.0

    Comprehensive Audit & Overhaul: Fixed live catalog render on show addition, normalized streaming service filters, added show deletion/removal, resilient offline/guest storage sync, and repaired modal layout structures.

  • Beta 0.5.0

    Pivot to Smart Watchlist: Added "Continue Watching", "Recommended For You", Custom YouTube TV additions, and Status Tracking.

  • Beta 0.4.1

    Converted Admin Panel to a clean Modal UI overlay to fix catalog visibility bugs.

  • Beta 0.4.0

    Implemented Cloud System Settings syncing.
