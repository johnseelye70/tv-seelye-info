Version History & Release Ledger

Beta 2.5.0

Administrative audit log and complete architectural release history.

  • Beta 2.5.0 Latest

    Multi-Device Tombstone Deletion Ledger & Resilient Cross-Device Sync: Resolved cross-device deletion resurrection bugs where stale mobile browser local storage (iPhone) inadvertently repushed cleared library items back into Supabase cloud storage upon refresh. Engineered a dual-layer deletion tombstone ledger (tv_hub_deleted_items / user_deleted_${userId} in PostgreSQL system_settings) tracking deleted content UUIDs, TMDB IDs, and titles. Enforced strict Read-Only Data Fetching push guards so background syncs, tab focus events, and mobile page loads never trigger cloud push side-effects. Integrated real-time WebSocket sync broadcasting across active browser sessions via Supabase Realtime (seelye-sync-relay), immediately removing deleted shows on connected devices without requiring manual page reload.

  • Beta 2.4.0

    iOS Safari Gesture Stability & Zero Side-to-Side Swirling: Eliminated horizontal elasticity and sloppy side-to-side rubber-banding on iOS Safari by locking the viewport scale (maximum-scale=1.0, user-scalable=no, viewport-fit=cover), enforcing strict touch-action: pan-y and overscroll-behavior-x: none on html, body, and main dashboard containers, and establishing boundary containment with overflow-x: hidden on body. Intercepted multi-touch gestures and multi-finger touchmove events in JavaScript to prevent accidental canvas shifting and pinch distortion while preserving fluid, native vertical scrolling, input typing, and horizontal carousel navigation.

  • Beta 2.3.0

    Local PC Hardware Bridge & Real-Time Relay Subsystem: Built an ultra-low-latency local Roku hardware bridge daemon (roku-bridge.js / start-roku-bridge.bat) running on the local network. Utilizing Supabase Realtime WebSocket broadcast channels, the bridge seamlessly receives remote keypresses, streaming app launches (Netflix, Disney+, Hulu, etc.), and episode casting commands from mobile browsers (iOS Safari / Android) over HTTPS without mixed-content or Private Network Access (PNA) restrictions, dispatching them directly to local Roku TVs on port 8060 in under 20ms. Features live bridge heartbeat monitoring, visual connection status pills, and automatic direct LAN fallback.

  • Beta 2.2.0

    Multi-Vector LAN Dispatching & Home Device Auto-Presets: Upgraded the client-side Roku ECP engine with multi-channel network dispatching (combining hidden-frame form submission, beacon POSTs, and asynchronous fetches) to bypass mobile browser active mixed-content promise rejections when sending commands to local Roku devices over Wi-Fi. Added auto-detected home network presets for Roku Ultra 4850 (192.168.50.9) and Roku Ultra (192.168.50.32), plus direct in-app guidance for enabling Roku’s “Control by mobile apps” permissive mode.

  • Beta 2.1.0

    Open Roku Device Setup & Episode Casting: Kept the Roku TV integration, remote control interface, and episode-level “Play on Roku” casting completely open to all users without requiring a master administrator password. Integrated an open, inline Roku Device Setup panel directly inside the virtual remote view so any device on the local network can configure and ping their Roku TV IP address instantly.

  • Beta 2.0.0

    Roku TV Remote Control & ECP Hardware Subsystem: Integrated direct client-side LAN communication with physical Roku streaming devices via the Roku External Control Protocol (ECP). Features an elegant 100% inline virtual remote control deck with tactile directional D-pad, transport controls (Play, Pause, Replay, Rewind, Fast-Forward), volume adjustment, universal system search launcher, and branded quick-launch channel tiles for Disney+, Netflix, Hulu, Peacock, Prime Video, Apple TV+, and YouTube. Added one-click “Play on Roku” actions to episode cards and persistent device configuration in Settings with live connectivity ping verification.
