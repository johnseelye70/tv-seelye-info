  • Beta 0.11.0 - IMDb Show Details Pop-up Modal: Decoupled show addition from card clicking so shows are only added via the explicit "+ Add to Library" button. Added multi-vector intelligent recommendation engine analyzing watch history, thumbs-up ratings, and genre profiles with contextual rationale badges.
  • Beta 0.8.0 - Streaming Service Discovery: Clicking any streaming service (Netflix, Disney+, Peacock, Hulu, Prime Video, YouTube TV) instantly displays currently popular and classic shows for that service with one-click library addition.

Made entire show card clickable for instant library addition with responsive visual feedback, resolved Supabase UUID formatting and guest mode storage persistence, and enabled Enter key search with catalog-to-TMDB fallback.

  • Beta 0.4.1 - Converted Admin Panel to a clean Modal UI overlay to fix catalog visibility bugs.
  • Beta 0.4.0 - Implemented Cloud System Settings syncing.
